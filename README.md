# Tok Rent – C# Year 3 Term 2 Final Project

Tok Rent is a Windows Forms application developed in C# as a final project for the third year of my bachelor's study, second term. The application serves as a rental management system, allowing users to efficiently manage rental items, customers, and transactions.

## Features
- **User-Friendly Interface**: Built with Guna.UI2.WinForms for a modern and responsive UI.
- **Rental Management**: Add, edit, and delete rental items and customer information.
- **Transaction Tracking**: Monitor rental transactions, including dates and statuses.
- **Search Functionality**: Easily search for items or customers within the system.
- **Data Persistence**: Store and retrieve data using local storage mechanisms.

## Installation

1. Clone the Repository:
```bash
git clone https://github.com/toto-thi/CSharp_Term2.git
```

2. Open the Solution:
- Navigate to the cloned directory.
- Open `Tok Rent.sln` with Visual Studio.
  
3. Restore NuGet Packages:
- Ensure all NuGet packages, especially Guna.UI2.WinForms are restored.
- If not restored automatically, use the NuGet Package Manager to install missing packages.

4. Build and Run:
- Build the solution to ensure all dependencies are correctly configured.
- Run the application to start using Tok Rent.

## Technologies Used

- **Programming Language**: C#
- **Framework**: .NET Framework
- **UI Library**: Guna.UI2.WinForms
- **IDE**: Visual Studio
- **Database**: MSSQL
